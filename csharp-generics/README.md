# C# Generics

A generic `Queue<T>` built in C# on a singly linked list, without `System.Collections` or `System.Collections.Generic`.

## Tasks

| Task | Folder | Description |
|------|--------|-------------|
| 0. Queue | `0-queue/` | `Queue<T>` class with `CheckType()`, which returns the queue's element type |
| 1. Enqueue | `1-enqueue/` | Adds a `Node` class, `Enqueue()` to add to the end of the queue, and `Count()` |
| 2. Dequeue | `2-dequeue/` | Adds `Dequeue()`, which removes the first node and returns its value |
| 3. Peek | `3-peek/` | Adds `Peek()`, which returns the first value without removing it |
| 4. Print | `4-print/` | Adds `Print()`, which prints the queue from the head |
| 5. Concatenate | `5-concatenate/` | Adds `Concatenate()`, which joins a queue of strings or chars |
